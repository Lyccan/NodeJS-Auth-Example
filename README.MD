This project was just a demo to example how to auth users and "protect" routes.
If you gonna use databases, you just need to implement the verification taking the user from the db.
Also, I don't recommend using routes like this, with res.sendFile(), think is much better fetch data from the frontend, but you can use it anyway for tests.
